目标：重构指标管理模块

# 参考资料
docs/development/mvp-development-plan.md里的闭环3的完成情况是docs/progress/mvp-loop-3-metric-registry.md。

# 需求
1.指标管理界面要求注册指标呈现卡片状态，支持搜索框按指标编码或名称匹配搜索对应指标卡，比如当前是【02080103重复内容程度】
2.指标卡点进去后是个窗口，在窗口里list出对应的计算器卡片，比如当前有【文本重复内容计算器】
3.选择对应计算器，点击执行按钮可以开始构建质量契约，前端会引导用户配置rule
4.构建完成质量契约后可以点击执行，开始异步进入后台评测流程
5.评测完成可以在【评测结果】模块里查看验证报告，【评测结果】模块可以在【本地验证报告】模块基础上改
