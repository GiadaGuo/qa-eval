
# 开发任务：为 qa-eval 新增森系 Welcome 首页

## 一、背景

当前项目 `qa-eval` 已经具有完整的前端功能页面，但缺少独立首页。

前端使用 React + TypeScript + Vite，已有统一的页面布局、导航和视觉配色。

本次只新增一个 Welcome 首页。

**严格要求：其他所有前端页面、业务功能、交互逻辑和后端 API 均保持不变。**

## 二、首页视觉设计

希望新增一个具有森林童话氛围的欢迎首页。

整体关键词：

- Forest aesthetic / Botanical
- Soft sage green
- Cream white
- Elegant and dreamy
- Minimal and peaceful
- Subtle motion

视觉风格要与当前项目已有的浅绿、浅蓝、自然系配色协调。

不要设计成传统数据管理后台 Dashboard，也不要使用大面积深绿色、复杂渐变或科技感粒子背景。

首页应当精致、轻盈、有留白，有一定的艺术感。

### 1. 中央 Welcome

页面视觉中心使用一个较大的英文单词：

**Welcome**

字体要求：

- 优雅的英文花体 / Calligraphy / Script。
- 有自然的手写笔触和流畅的字母连接。
- 具有精致、浪漫但不过度繁复的气质。
- 不使用普通无衬线字体代替。
- 推荐先评估 Great Vibes、Allura、Parisienne 等字体的实际效果，选择最适合的一款。
- 字体需要正常加载，并提供合理的 fallback。

Welcome 应成为整个页面最突出的视觉元素。

可以在下方加入一行非常克制的辅助文字，例如：

*A little space to explore, discover and create.*

但不要堆积大量文案。

### 2. CSS3 小兔子动画

参考：

https://www.bootstrapmb.com/item/12694/preview

该参考是使用 CSS3 绘制并通过 keyframes 实现跳跃的小兔子动画。

希望首页中出现一只可爱、柔和、精致的小兔子。

要求：

- 优先使用 CSS3 实现兔子造型及动画。
- 可以参考原示例的运动效果，但不要机械复制整套网页。
- 兔子应融入森系页面，而不是独立突兀的卡通组件。
- 动画可以包含轻微跳跃、耳朵摆动、身体起伏或地面阴影变化。
- 动画节奏自然、柔和，不要高速循环或夸张弹跳。
- 可以设计兔子在 Welcome 下方的草地附近活动。
- 避免动画遮挡标题和主要按钮。
- 支持 `prefers-reduced-motion`。
- 尽量避免依赖 JavaScript 定时器实现动画。

请根据参考效果和当前项目视觉风格自行确定最合适的兔子大小、位置及运动轨迹。

### 3. 森系背景

背景建议采用：

- 奶油白或非常浅的鼠尾草绿底色。
- 柔和的植物、叶片、草地或森林轮廓。
- 少量精致装饰。
- 自然柔和的光感。
- 适当的层次和空间感。

不要让背景喧宾夺主。

可以使用 CSS、SVG 或经过优化的图片素材，但优先保证整体美观和加载性能。

### 4. 进入系统

Welcome 首页需要有一个与整体风格一致的「进入系统」按钮。

要求：

- 点击后进入项目现有的主要功能页面。
- 保留原有导航及全部页面路径。
- 不影响用户直接访问已有深层路由。
- 不增加不必要的登录、引导或配置步骤。

## 三、路由与架构约束

请先检查现有 React Router 或其他路由实现。

要求：

1. 将 Welcome 首页作为应用的 `/` 路由。
2. 原有功能页面的路由保持不变。
3. 不修改现有业务页面内部实现。
4. 不改变现有 API 请求行为。
5. 不改变原有状态管理与数据流。
6. 如果需要调整默认路由或 Layout，只进行最小必要修改。
7. 不要让 Welcome 页意外继承后台页面的复杂布局。
8. 浏览器刷新及直接访问旧路由均正常。

首页应作为独立组件实现，避免将动画和首页样式散落到现有业务组件中。

CSS 类名应适当隔离，避免污染已有页面。

## 四、素材使用

请先判断能否仅使用：

- CSS3
- SVG
- 现有项目资源
- 合理的免费字体

完成设计。

如果需要额外的森林背景图片、插画或特殊字体，请先明确说明：

1. 需要什么素材。
2. 推荐的素材格式和尺寸。
3. 素材放置路径。
4. 是否有授权或使用限制。
5. 没有该素材时能否使用 CSS/SVG 替代。

**如果确实需要我提供素材，请先停止开发并向我说明，不要自行使用质量较差的占位图片。**

如果不需要额外素材，则直接实施。

## 五、实现与验收

请直接基于当前项目开发，复用现有设计规范，不需要编写单独的架构规划文档。

完成后检查：

- 首页整体视觉效果。
- Welcome 花体字体显示。
- 兔子 CSS3 动画是否自然。
- 桌面和移动端适配。
- 动画性能及 reduced-motion 兼容性。
- 进入系统按钮。
- 原有页面和路由是否正常。
- 前端 TypeScript、lint 和 build。

不要进行无关重构。

完成后说明修改文件、首页访问地址、素材依赖和测试结果。

**最终目标：新增一个精致、自然、温柔、带有 CSS3 小兔子动画的森系 Welcome 首页，同时确保现有所有前端功能完全不受影响。**
