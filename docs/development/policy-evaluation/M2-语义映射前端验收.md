## 改动

- `RawDatasetVersionPanel.tsx` 显示版本与发布状态、映射统计和历史修订。左侧按通用、领域、自定义筛选语义，支持搜索和确认状态。右侧配置来源字段与版本化 Transform，展示服务端返回的原始值、解析值、表示、字段路径、状态和诊断。Schema 与样本原文可折叠。
- `datasetVersions.ts` 扩充 M1 请求和响应类型。推荐只追加未绑定项。编辑后的绑定恢复待确认，预览和逐条确认会先保存待提交的编辑。草稿必须保存后才能发布，发布对话框明确展示已确认和待确认数量。
- `Dashboard.tsx` 和 `DatasetVersionPage.tsx` 沿用数据集详情入口。v3 首次进入后在现有地址记录 `rawVersion`，刷新可恢复同一版本及服务端草稿。v2 使用原有详情和编辑器。
- `RawVersionEvaluation.tsx` 保留已有正文完整度评测与报告入口。`semanticDraft.ts` 与定向测试覆盖推荐去重、保留人工确认和同字段的不同表示。

## S0 浏览器验收

使用隔离数据库 `data/runtime/policy-s0/platform.sqlite3`、本地原件及就绪索引。数据版本 `01a21137-724b-7691-8a60-4fa110654627`，数据集 `policy.policy`，321,902 条记录。

1. 从「数据管理中心 → 版本管理 → 详情」进入，展开并逐行核对 **39 个原始字段**。页面显示模板匹配及 **16 条推荐**。
2. 对同一真实样本预览三项绑定。标题的原始值与解析值相等，HTML 正文按原值显示，派生纯文本的输入与 HTML 原值一致，输出由后端 `html_to_plain@1.0.0` 产生。
3. 将一条待确认绑定临时指向 `targetContent`，页面显示真实 `NULL` 和同名诊断，随后恢复原业务字段。将已确认的标题暂改为 `iid`，确认状态恢复待确认。保存并重载页面后仍显示 `iid` 与待确认。恢复 `title`，预览并逐条确认三个目标。
4. 发布前显示 **3 项已确认、13 项待确认**。发布 API 返回的新修订只包含 3 条已确认绑定。新默认摘要为 `sha256:470b604477654f646c76abdb23008cbc9a162d718cf9458533dbdae9c0c895dd`。
5. 选择 S0 旧摘要，检查来源字段不可编辑且仍可按历史摘要预览。将旧修订设为默认后再切回新修订。基于新修订生成草稿，3 条绑定均待重新确认。应用 16 条推荐新增 13 条待确认绑定。保存并重新确认 3 项，最后刷新仍为 **3 项已确认、13 项待确认**，默认摘要为新修订。业务码表、日期和附件关系没有被补充或确认。

## 测试及边界

- 前端测试 **21 通过**，包括 2 个 M2 推荐回归。TypeScript 类型检查、改动文件 ESLint、Vite 生产 build 通过。Vite 仍报告大分包提示。
- 验收通过已存在的 `s0-v3` 版本执行。没有重新发布数据集、复制原件、发起评测或更改后端契约。
- 自定义语义登记沿用 M1 的新增能力。真实 S0 数据没有添加测试用语义。历史列表按 API 上限每次加载 20 条。

## 「确认字段映射」入口补验

版本列表的「确认字段映射」现在直接打开已发布 v3 的语义映射。已有 JSONL 的草稿从同一入口进入语义映射发布步骤，用户显式发布原始数据后继续进入编辑器。该步骤复用现有发布 API，读取本地原件构建索引。需要继续 v2 流程时可选择「使用 v2 字段映射」。新增定向回归验证 `NEEDS_MAPPING` 草稿发布 v3 后清除旧流程状态，并在版本列表和详情返回 v3 标识。后端定向 8 项、前端 21 项和 build 通过。此入口修复未在截图中的 321,902 条草稿上执行发布。
