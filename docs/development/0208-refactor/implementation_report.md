# 0208 重构实施与验收

## 迁移与调用

0208@2.0.0 注册八个槽位，保留七个原子编码的标准引用。五个槽位可执行：跨记录重复、记录内重复、文本困惑度、文本完整程度、文本纯净程度。后三项复用原 Calculator，其中困惑度需要本地 KenLM 模型。知识信息密度、信息缺失程度和文本连贯程度延续原语义映射，新版 Binding 停用，等待离线实现。

Registry Binding 的 compatibility 保存槽位标识、主测量、执行粒度与标准映射。向 `POST /api/v1/quality-contract-versions/multi` 提交 0208@2.0.0 的多个 items，每项可给定 `operator_slot`，服务按优先级、版本、Calculator key 确定一个实现，也接受显式固定版本。发布后的 Contract 绑定版本与参数。Planner 校验同槽位仅一个实现，一个槽位对应一个直接执行 Stage。已发布的旧版定义、Binding、Contract 及历史 Run 沿用原路径。新版与旧版清洁度条目在同一新 Contract 中互斥。

Web 指标详情可勾选算子，按槽位选择实现和填写参数 JSON，发布观察型 Contract，查看各结果状态、测量值及索引证据预览。阈值型 Contract 可使用同一个多项 API 配置。记录内阈值参数可直接在 Web 填写。两个重复算子复用 0207 LegacyAdapter 和 FieldView、平台 Worker、JSONL Evidence 索引、QualityIssue 和 Report。记录内检测以 RECORD 为执行粒度，跨记录检测以 DATASET 为执行粒度。两者发布数据集级 MetricResult，分别用 GROUP 和 SAMPLE 标识 Issue 主体。

## 计算口径

### 跨记录重复

- 必须显式提供 `fields`，支持内容角色及 JSON Pointer。默认策略为 `record_exact`，对所选字段的有序规范化序列做 SHA-256。字段精确策略比较同一选择器下的规范化值。指针可指定结构化值类型，无默认技术字段。
- 流式读取 SampleRecord JSONL，使用临时 SQLite 索引保存全局数据。近似策略复用 MinHash，按 32 个签名分为 8 个 band，先召回，再计算字符 5-shingle 的实际 Jaccard。缺省 `near_threshold` 只产生候选，提供阈值后按包含边界的规则确认。近似组为一条直接确认的记录对。
- 按输入顺序确定保留记录。仅直接匹配更早的保留记录时，才计为冗余。跨策略合并记录标志，确认组按成员集合去重，保留各策略的独立证据行。相似链的中间记录若已判冗余，后续记录仅匹配该记录时仍保留。
- 受影响率、冗余率、候选率以至少一个策略可计算的记录数为分母。候选率统计曾进入 LSH 候选的记录，包括复核通过的记录。覆盖率以全部输入记录为分母。空有效集返回 MISSING。主项是冗余率，算子分为 1 减冗余率。
- 每 band 默认最多保留 32 个候选索引成员，每次每字段最多复核 256 对，默认仅对长度 5–20,000 的字段做近似计算。近似证据默认上限 10,000 行，证据上限不截断测量。饱和探测、进入近似索引的记录数及省略证据数写入 Stage 诊断。桶容量、长度限制、抽样校准和数据分布会影响召回。精确证据包含组 ID、代表样本及成员，近似证据包含两端字段来源、判定与相似度。

### 记录内重复

- 在所选正文上按空行取段落，按标点与换行取句，规范化后 Hash。可启用固定宽度字符 n-gram 检查局部片段。默认排除 Markdown 引用行与可识别的 Markdown 表头，可配置正则排除固定术语、其他表头和引用格式。最小长度默认 12，属于运行参数。
- 同一字段的后续出现区间取并集。同一原文指针通过多个选择器命中时计一次。证据坐标是所选文本的 Unicode 码点半开区间。有效字符排除空白和过滤命中，重复率为冗余字符数除以有效正文字符数。字符加权聚合给出数据集级重复率及主分 `1 - 重复率`。
- 配置 `repetition_threshold` 后，记录的重复率小于等于阈值记 1，超过记 0，输出记录失败率诊断。未配置阈值时，记录保留测量及 `NOT_EVALUATED` 判定。缺失和证据不足的输入计入排除，全部排除时结果为 MISSING。记录内位置通过 SAMPLE Issue 挂接到证据。

Report 为槽位输出主测量、诊断和可计算的 0–1 算子分。PPL 保持原值。正式 Metric Score 依赖后续权重和校准，本次为空。诊断统计及未确认的 LSH 候选不计分。

## 验收与性能

- SQLite 与临时 artifact store 的隔离 Run 覆盖 Contract 发布、规划、Stage 执行、结果持久化、证据索引、Issue 和 Report。合成用例核对同槽位重复选择拒绝、版本固定、两个重复槽位同时执行、KenLM 缺模型时失败隔离、标准映射、精确策略去重、近似候选复核、非传递性、记录内区间并集、局部片段、字段指针、合理重复过滤、空值和阈值边界。
- 旧版 Contract、Calculator、Report 通过历史路径回归。真实验证读取既有政策 DatasetVersion 快照的前 64 条正文，在临时存储重新构建小样本并执行两个新算子。跨记录有效样本 61 条，确认组 0；记录内字符加权冗余率约 0.4804%。这两个测量来自不同评测主体。
- 单独运行政策样本验证，准备、注册、运行、报告及读取约 0.233 秒，约 274 条/秒，测试进程峰值 RSS 102.5 MiB，两个算子证据共 17,976 字节。按该批次吞吐粗估 32 万条约 19.4 分钟，按证据密度外推约 90 MB。小批次耗时含固定启动开销，长文本、候选密度、桶饱和、存储 I/O 和 Issue 数量会改变全量量级；这组数字不构成全量 SLA。
- Web 构建及 19 条 Web 测试通过。浏览器交互未做人工验收。Vite 有构建产物体积提示。

未使用 LLM 或在线嵌入，未启动 32 万条正式评测。三项语义能力、正式组合权重、近似阈值与全量资源预算仍待验证或校准。未测标注真值准确率。

最终回归覆盖 `tests/unit`、`tests/contracts`、0208 隔离 Run、旧困惑度/纯净度 Run、Registry API 和 Contract API，共 527 例通过。
